# Druug Consult

A responsive one-page website for Druug Consult, a medical quality assurance consultation firm. Built with plain HTML, CSS, and JavaScript; no build step or runtime dependencies required.

## Preview locally

Open `index.html` in a browser. For local hosting, serve this folder with any static web server.

## Publish with GitHub Pages

1. Create a GitHub repository and add the files in this folder.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, select your default branch and `/ (root)`, then save.
4. GitHub Pages will publish the site at the URL it displays.

## Customize

- Update page content and email links in `index.html`.
- Adjust colors, typography, and responsive layouts in `styles.css`.
- The small navigation menu and dynamic copyright year are handled in `script.js`.

All inquiries use `mailto:druugconsult@gmail.com`. Fonts are loaded from Google Fonts when a visitor is online; the site remains usable with system fonts if they are unavailable.
